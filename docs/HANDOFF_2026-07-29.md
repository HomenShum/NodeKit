## Traps that cost real time here

- **`cmd | tail; echo $?` gives you `tail`'s exit code.** This was hit three times in one session,
  including by the person documenting it. Capture the exit on its own line.
- **A background wrapper's exit code is not the wrapped command's.** Twice a run was reported as
  exit 0 while its own captured `EXIT=` line said 1.
- **`git status` reports a CRLF file as clean** when `.gitattributes` normalizes it. `src/cli.mjs`
  carried 1,931 CRLF pairs while the index was pure LF. Use `git ls-files --eol`; look for
  `w/mixed`. npm's `bin-links` rewrites the first shebang of a declared bin from CRLF to LF at
  install time, which broke the packed-vs-installed manifest check by exactly one byte at offset 19.
- **`npm pack` runs `prepare`**, so packing is not a pure read. The consumer-package verifier now
  proves the supplied archive against the exact clean tracked distribution manifest without invoking
  a second pack lifecycle.
