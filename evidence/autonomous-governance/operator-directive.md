# Operator directive: proof-backed reversible autonomy

Source: direct operator instruction in the active Codex session on 2026-07-30.

The operator directed NodeKit to replace immediate human approval for reversible architecture changes with:

- exact live before and after request/response evidence;
- screenshots or clips for changed UI surfaces;
- an at-a-glance before/after journey when no product UI exists;
- uninterrupted execution with an explicit rollback path; and
- later human feedback that can accept the result or trigger rollback.

The directive does not waive pre-action review for destructive writes, credentials, irreversible migrations, material spend, external communication, or legal and compliance commitments.

Assurance boundary: this artifact records an operator direction from the active session. It is not a signed canonical-event approval and must never be represented as one.
