# Changelog lane format

Create one file per user-facing or maintainable surface. Put the newest entry directly below the
header, use `YYYY-MM-DD`, explain what changed and why, and cross-link related lanes.

```md
## YYYY-MM-DD — Short imperative title
What changed and why. Note the user-visible or maintainer-visible effect.
**Commit**: `this commit`. **Author**: Codex.
**Touches**: `CHANGELOG/path/to/related-lane.md`
```
